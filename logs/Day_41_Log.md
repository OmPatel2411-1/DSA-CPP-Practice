## What I Learned

* Preorder traversal follows the order: Root → Left → Right.
* Inorder traversal follows the order: Left → Root → Right.
* Recursive DFS provides a simple way to implement tree traversals.
* The same traversal concepts can later be implemented iteratively using a stack.
* Understanding traversal order is essential before moving to more complex tree problems.
