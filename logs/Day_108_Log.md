## Key Learnings

- Dijkstra's algorithm finds shortest distances in weighted graphs with non-negative edge weights.
- Path counts must be updated when a shorter route or an equally short route is discovered.
- Reachability queries can be handled using graph traversal or transitive-closure techniques.
- Choosing an approach depends on graph size, constraints, and the number of queries.
