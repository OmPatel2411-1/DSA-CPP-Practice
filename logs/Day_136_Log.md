## Key Learnings

- Duplicate values can make it difficult to identify which half is sorted.
- When `nums[left] == nums[mid] == nums[right]`, shrinking the boundaries may be necessary.
- Binary search with duplicates can have O(n) worst-case time complexity.
- Always analyze edge cases instead of assuming every binary-search problem guarantees O(log n).
