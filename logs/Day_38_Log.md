## What I Learned

* Prefix sums can be combined with a Hash Map to count subarrays efficiently.
* The key idea in Subarray Sum Equals K is using previously seen prefix sums instead of checking every subarray.
* A Hash Set can identify consecutive sequences efficiently.
* In Longest Consecutive Sequence, starting only from numbers that have no predecessor avoids unnecessary repeated traversal.
* Choosing the right data structure can reduce a problem from quadratic time to linear time.
