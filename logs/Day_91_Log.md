## Learning

Coin Change II reinforced the difference between combinations and permutations. The order of the DP loops matters when counting combinations with unlimited use of each coin.

Last Stone Weight II can be transformed into a partition problem where the goal is to minimize the difference between two subsets.

## Key Takeaway

0/1 Knapsack → each item can be used once.

Unbounded Knapsack → an item can be used multiple times.

The correct DP state and loop order are critical to getting the intended result.

## Mistakes / Improvements

* Carefully identify whether the problem is 0/1 or unbounded.
* Check loop direction when using 1D DP.
* Distinguish counting combinations from counting permutations.
* Look for subset-sum transformations in partition problems.
