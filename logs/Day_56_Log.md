## What I Learned

* A Min Heap can efficiently maintain the k largest elements seen so far.
* When the heap size exceeds k, removing the smallest element keeps only the most relevant elements.
* Priority Queues are useful when repeatedly selecting the most important element.
* For distance comparison, `x² + y²` is sufficient; calculating the square root is unnecessary.
* Heaps provide an alternative to sorting when only a limited number of elements are required.

## Reality Check

A Heap is not just "another sorting technique."

The useful pattern is recognizing when the problem only needs the best or worst k elements instead of the entire dataset being sorted.

That distinction can reduce unnecessary work significantly.
