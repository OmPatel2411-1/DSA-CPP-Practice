## What I Learned

* Two pointers can efficiently track the left and right boundaries.
* A Hash Map can maintain character frequencies inside the current window.
* In Longest Repeating Character Replacement, the condition can be expressed using the window size and maximum character frequency.
* Sliding Window is especially useful when a problem asks for the longest or shortest contiguous substring satisfying a condition.
