## 🧠 What I Learned

* A graph is bipartite when its nodes can be divided into two groups such that adjacent nodes belong to different groups.
* BFS/DFS can be used to assign alternating colors to nodes.
* A graph can contain cycles, so tracking visited nodes is essential.
* Graph cloning requires maintaining a mapping between original nodes and their corresponding cloned nodes.
* Hash maps are useful when a graph node needs to be associated with its cloned counterpart.
