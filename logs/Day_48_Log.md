## What I Learned

- A 2D grid can be treated as a graph where adjacent cells represent connected nodes.
- DFS and BFS can both be used to explore connected components.
- In Number of Islands, every unvisited land cell can represent the start of a new connected component.
- Flood Fill requires tracking the original value before modifying connected cells.
- Edge cases such as `newColor == originalColor` should be handled before traversal.
